# 💼 JobTrack – Job Application Tracker

JobTrack is a simple and responsive **Job Application Tracker** that helps users manage and organize their job applications in one place.

Users can add applications, update their status, search and filter applications, edit or delete records, and manage application data easily.

---

## 🚀 Features

- 📊 Dashboard with application statistics
- ➕ Add new job applications
- ✏️ Edit existing applications
- 🗑️ Delete applications
- 🔍 Search applications by company or job role
- 🔽 Filter applications by status
- ↕️ Sort applications
- 🏷️ Application status badges
- 📅 Track application dates
- 🔗 Store job URLs
- 📝 Add notes for applications
- ⚙️ Settings panel
- 🌙 Dark Mode
- 🧹 Clear all applications
- 📱 Responsive design for desktop, tablet and mobile
- 💾 Local data storage using LocalStorage

---

## 📌 Application Status

JobTrack supports multiple application statuses:

- Applied
- Interview
- Selected
- Rejected
- Offer
- Withdrawn
